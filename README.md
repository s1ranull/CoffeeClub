# CoffeeClub

Flutter-приложение кофейни для лабораторной работы №5. Меню, заказы и бонусные
операции хранятся в SQLite. Клиент обращается к Python API по HTTP. Навигация
работает через go_router, состояние экранов — через Provider.

## Запуск на Windows

Нужны Python 3.9 или новее, Flutter с Dart 3.13.4 или новее в ветке Dart 3,
Android SDK и запущенный Android-эмулятор.

В первом терминале из корня проекта запусти сервер. Python-пакеты отдельно
устанавливать не нужно. Файл `server/app.db` создастся при первом запуске.

```powershell
py -3 server\app.py
```

Проверить сервер можно в браузере по адресу http://localhost:8080/health.
Оставь сервер запущенным. Во втором терминале из корня проекта выполни:

```powershell
flutter pub get
flutter run
```

На Android-эмуляторе приложение подключается к `http://10.0.2.2:8080`.
При первом запуске выбери регистрацию и создай аккаунт. Для нового аккаунта
сервер создаёт стартовое меню.

## Проверка

```powershell
flutter analyze
flutter test
```

Для ручной проверки добавь товар и найди его по названию, оформи заказ, затем
перезапусти приложение и проверь историю заказов. Чтобы проверить ошибку сети,
останови сервер и обнови меню. Запусти сервер снова и нажми «Повторить».
