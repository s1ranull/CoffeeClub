# CoffeeClub

Flutter-приложение кофейни для лабораторной работы №4: меню, заказы и программа
лояльности. Состояние управляется через Provider и ChangeNotifier, навигация —
через go_router. Данные хранятся в памяти mock-репозиториев и сбрасываются после
перезапуска; подключение к серверу не требуется.

## Возможности

- Локальный вход, профиль и выход из приложения.
- Каталог напитков, выбор размера, добавление, редактирование и удаление товаров.
- Корзина с изменением количества и удалением позиций.
- Оформление заказа с проверкой контактных данных и история заказов.
- Начисление и списание бонусных баллов, баланс и история операций.
- Состояния загрузки, обработка ошибок и повторная загрузка. В профиле можно
  включить симуляцию сбоя сети.

## Запуск

Требуются Flutter SDK с Dart `>=3.13.4 <4.0.0`, Android SDK и запущенный Android-
эмулятор либо подключённое устройство с включённой отладкой по USB.

Из корня проекта:

```bash
flutter pub get
flutter run
```

Для входа используйте любой корректный e-mail и пароль длиной от 6 символов.
Авторизация локальная, пароль не сохраняется.
